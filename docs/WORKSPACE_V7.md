# 按需解题、点选填写与识别准备（2026-10-31）

仅修改本轮要求：去掉机器人下方标题，改为聊天自我介绍；同一框内放大单个机器人；点击元件定位、滚动并聚焦右侧数值框（手机切换到调参）；空值保持空白。点选延迟到鼠标/触摸释放，拖动不抢输入焦点，开关仍正常切换。其余单屏布局及功能沿用V6。

## 解题与填写

默认手动调参，识图不自动填答案。用户明确请求解题时，后端根据已记录的独立测量、单位和开关条件进行有界逆向MNA计算；仅未知电源电压、电阻/两端滑变，最多4个未知量/24个元件。要求约束足够、Jacobian满秩，多初值一致及测量回代匹配；保持原图开关初态。重复约束、欠定、矛盾、未收敛、未知单位/开关状态拒绝自动填值。学生此前的计算结果不作为原题约束。

明确要求“解题并填入答案”才直接应用已核对的参数，支持撤销。只要求计算/核对时返回答案，不改当前参数。所有已填参数也会按题目条件核对，不因为能求出当前读数就宣布答案正确。需要时将当前会话原图和补充题干发送到同一个AI Circuit接口独立提取已知条件；原题与当前已知参数冲突时先提示，不覆盖。没有足够条件不编造数值；这不是任意物理文字题的通用解题器，超出模型范围继续明确提示。

确定性检查包括原题R1=30Ω、只闭合S1电流0.3A、S1/S2闭合0.5A，得15V/20Ω，保持初始开关断开。另核验欠定/重复条件不填值、默认操作不触发解题、后端有记录条件时无需模型即可完成解题填写。解题数值不直接信任LLM生成。

## 响应速度与识别边界

上传完成后即在浏览器内预先准备原图、高清裁图、触点栅格与候选，最后一张图的准备结果仅存本页内存；点击生成时与哈希并行，避免重复解码、裁图和像素扫描。没有降低分辨率、减少元件独立读取、拓扑追踪、像素核验或分歧复核。首次请求仍受模型推理与网络时间影响，不宣称新的固定秒数或统计准确率。本轮未重复调用真实识图接口。
