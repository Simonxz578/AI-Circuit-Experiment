# 开关初态与多模态识别修复（2026-10-31）

原图中的 S1、S2 都断开。题干“只闭合 S1 时”“再闭合 S2 后”描述后续实验，不能当作图示初态。旧版仅依赖一次模型输出，既可能混入题干操作，也可能在接线正确时仍误判触点。连续复测说明，重复问模型也可能得到相同错误，不能把模型间的一致当成像素事实。

## 当前流程

1. 完整原图读取元件与明确给定参数，未知参数保持 null；不求解、不执行题干操作。
2. 根据长导线定位电路区域，保留四周标号。接线阶段读取电路裁图和独立给定值，不再读取题干的后续操作条件；用低强度推理追踪实际端子，闭合开关仍保留两个独立端子。
3. 浏览器从原始像素提出圆形触点位置，候选不含答案、元件ID或开关状态。两个视觉阶段分别把开关标号对应到候选序号。
4. 后端在局部二值图里检查转轴和对侧触点的连通性，绕过空心转轴的白色中心；不借用另一条电路支路证明触点接触。同一触点不能验证两个开关。定位不一致、触点不可确认时显示“待确认”，不缓存或自动使用猜测初态。
5. 本地 schema、元件清单与数值比对及潜在回路检查发现分歧时，最多再复核一次。用于连通性检查的单位值仅为内部探针，绝不写回题目参数。接线仍是视觉模型识别结果，不能把清单核对冒充两份独立接线证明。

触点检查针对可清楚辨认的示意图。缺少可靠转轴/接触区域或图像模糊时保留人工复核。灯泡等超出线性直流模型的器件保留类型，不替换成电阻或伪造数值。
