# 单屏实验室与输入修复（2026-10-31）

本轮落实截图与随后交互反馈，沿用原仓库、Pages与Worker。主页面改为顶部拍题/文字 → 单个机器人与聊天 → 电路/调参；删除宣传大标题、装饰段落和底部重复区域。桌面同屏查看电路与侧栏；手机切换电路/调参，聊天及参数各自滚动，不拉长主页面。保留拍照、语音、导入导出、撤销重做。

## 根因与处理

- 数字框原先每按一键就Number转换、验证、重建历史，使空字符串、小数中间态无法稳定输入。新输入在本地保留完整文本，失焦/回车提交，支持单位；不再依赖上下箭头。滑条支持未知值，范围在一次拖动期间固定，使用帧合并预览，结束只提交一条历史。历史和游标合并为原子状态。
- 拖元件原先每个移动事件都会重跑布线。现在拖动中只预览元件位置，松手后才按真实节点重新布线；数值改变不重新布线。
- 修改确认曾直接串出a/b、n1/n2和参数对象。现在根据前后电路差异输出自然中文，如“新增电压表VM2，并联在R1两端”；内部节点和参数设置仅在主动展开的高级工具中出现。
- 电表缺少直接填写入口。现在所有电表都有“自动测量”和“你的计算结果”；输入结果进入独立测量层，不伪造或覆盖物理读数。电压表默认无限电阻，电流表默认零电阻，内阻与最大显示值移入高级设置。LED导通电压直接可填写；没有该参数不编造导通读数。
- 识别后聊天明确指出缺少的参数，询问是否填入学生算出的结果。本地可一次处理“R1=15Ω，电源=6V”等多项答案，也能记录电表示数，不调用AI、不自动解题填答案。

## 失败图与识别边界

截图错误文案对应OUTPUT_TRUNCATED分支。没有那次请求ID和原始供应商响应，不能还原它的完整token轨迹；代码中确认旧主识别/恢复预算均为6000，且没有SPDT三端结构。现在拓扑输出只含核心接线，原始单位/测量由元件阶段保存；恢复截断时提供更大的独立输出预算，仍最多三次上游调用。

增加SPDT的公共端、接点1、接点2真实连线与0/1/2档，绘图布线、schema、识别和直流求解一致。截图中刀片未接触任一触点，显示断开；现有像素检查尚不能独立证明三档接触，保留“请确认位置”，不冒称自动验证通过。

仅对用户这张SPDT原图执行一次真实图像任务（两个模型阶段），返回200，用时17.391秒。人工核验与本地端子断言确认电源、电容、R1、R2及K三个接点正确；[记录](evidence/workspace-v6/targeted-recognition.json)。图片留在忽略的私有目录。这里没有宣称所有图像都有某个统计准确率，首次识别时间仍随模型负载波动。
