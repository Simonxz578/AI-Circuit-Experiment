# V5：单位、测量与编辑（2026-10-31）

本轮按 V5 提示文件增量修改原仓库，沿用同一 Pages、Worker 和 AI Circuit 专用 Secret；没有读取 Ninefold 凭据。保留蓝色单页、中文名称、机器人、原图缩略图、导入导出及既有 MNA 网络结构。

## 实现

- `src/circuit/units.ts`、`recognition.ts`、`schema.ts`：统一 SI 解析，支持 k/M/m/μ/u/n/p。明确原始表达优先规范化，例如 rawValue=2、rawUnit=kΩ 转成2000Ω；100μF转成0.0001F。保留原始表达、来源、置信度、参数字典及可选端子映射。单位无法解析时置空并标为待确认，不猜值。画布使用工程单位显示；属性输入可带单位；读数CSV保留SI、原始单位与来源。
- `CircuitCanvas.tsx`：补充电容双板、极性电容、LED/二极管与A/K、发光箭头、电感、灯泡、保险丝、交流源、热敏/光敏电阻、稳压二极管、马达、检流计图形。方向由端子a/b及布局朝向决定，几何仍与电连接分离。
- `Measurements.tsx`：题目条件独立于元件数值，支持I/U/P/Q、目标元件、适用开关状态、原始表达、来源与证据。可增删改、待求标注；图中条件徽标和悬停说明、侧栏原题/当前仿真/差值分开。开关条件不一致或置信度不足时不比较。标注绝不自动填入待求电阻、电源或当前开关状态。
- `operations.ts`、`commands.ts`、Worker提示：增加任意已登记两端元件的添加、替换、泛化串/并联、仪表串入/跨接、模型参数、标注增删改、建立/拆分节点。保留白名单验证、确认草案及撤销重做。测量对象不明则询问；两端等效滑变支持总电阻×滑片位置。不同物理量间替换会清空旧数值。
- `solver.ts`：继续使用原MNA。电容按明确标出的直流稳态开路，Q=C×U；不模拟瞬态。LED/普通二极管在明确填写正向压降后采用恒定压降近似，用最多8个器件的有界状态枚举核对正反向约束；缺参数、浮置或冲突不返回假数值。仪表/电源的内阻可显式填写；量程与读数分别保存。
- `Chart.tsx`、`plot.ts`：电阻起点不再静默改成0.001Ω；拒绝0Ω扫描边界，默认区间覆盖当前值。扫描数据仍逐点来自同一确定性求解器，不由模型生成。

## 明确边界

- 这不是通用 SPICE。LED恒定压降近似不描述指数特性、反向击穿、温度或动态。
- 电容仅直流稳态；复杂RC瞬态、多储能元件时间响应、电感/交流、马达、热敏/光敏随环境变化、稳压管击穿、灯泡非线性尚未启用数值求解。
- 当前交互式网表和标准布局仍主要是两端元件。三端电位器、SPDT和变压器没有冒充两端模型；附加端子映射可保存/校验，但多端求解明确拒绝，完整多端布线与图形仍未实现。
- 量程只用于显示，不模拟指针饱和；电表内阻另行参与MNA。
- 元件原值仍使用兼容字段value（SI）；parameters为额外模型参数。没有自动猜测缺失单位，也不承诺任意低清图片OCR必然正确。
