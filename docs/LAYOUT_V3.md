# 电连接、布局与速度修复（2026-10-31）

旧版本把模型的绘图坐标直接用于渲染，平行支路可能占据同一个位置；模型节点坐标与元件位置混用，还造成回线绕过符号、标签叠在开关上。识别出元件不等于画对电路。

## 当前实现

1. DeepSeek 只返回元件、a/b 端子、节点、给定值与不确定连接，不生成坐标，不解未知参数。
2. 本地按真实端子归并理想导线，做通用串并联分解；无法分解的桥式网络使用分散网格。所有原始元件和端子保留，不套用预置示例。
3. 支路分行，符号与标签独占区域；A* 在区域之外布线。不同网络禁止共用导线段；正交跨线留白，相连分支画实心点。同一网络先画全部线底再画导线，避免端点被自己的线底擦断。
4. 图形与求解分离。调参数、通断开关不触发布局；拖动只改变手动位置并重新绕线。支持缩放、平移和居中。
5. 页内 SHA-256 输入键缓存：最多三份、十分钟、只保存无需复核的成功结果；复制隔离，刷新清除。不保存图片到 localStorage。「重新识别」绕过复用。首次请求仍显示真实等待时间，复用显示“已复用本次识别”。
6. “让电路动起来”旁固定显示机器人；等待和搭建时左右双臂相向充能，胸口与能量轨迹同步，双眼为白色闪电。减少动画偏好时保留静态充能姿势。

## 真实接口测量

自制公开测试图，直接调用真实 DeepSeek `deepseek-flash` / low / 首轮 6000 token；无 mock、无二次恢复。原始结构化结果：[real-benchmark.json](evidence/layout-v3/real-benchmark.json)。

| 输入 | 识别耗时 | 输出正文字符 | 本地排版耗时（本机） | 核验 |
|---|---:|---:|---:|---|
| 两开关旁路 | 6.989 秒 | 426 | 23.5 ms | S2 与 R2 同端子；四态总电流 0 / 0.4 / 1.2 / 0 A |
| 仅给出 R1+R2=30Ω | 15.312 秒 | 426 | 8.4 ms | 三个独立参数均保留 null，不把总阻值塞给 R1 |
| 串并联混合 | 4.185 秒 | 317 | 9.0 ms | 12V / [2Ω + (6Ω∥3Ω)] = 3A |

每张图导线穿入其他元件区域的数量均为 0。耗时是本次采样，不是延迟上限；外部服务波动仍存在。没有关闭推理来换取可能错误的端子结果。缩短本地逐项搭建间隔为 160ms；首次识别主要仍由供应商处理时间决定。
